# Code of Conduct

## Our Pledge
We pledge to maintain a harassment-free experience for everyone, regardless of:
- Technical skill level
- Background or identity
- Experience with security topics

## Our Standards
Examples of encouraged behavior:
- Using inclusive language
- Respecting different viewpoints
- Graceful acceptance of constructive criticism

## Unacceptable Behavior
This repository will not tolerate:
- Sharing illegal hacking tools or techniques
- Encouraging unethical behavior
- Harassment of any kind
- Disclosure of vulnerabilities without permission

## Enforcement
Violations may result in:
- Removal of content
- Blocking from the repository
- Reporting to GitHub or authorities for serious offenses

## Contact
Report concerns to the repository maintainer privately.
