Contribution Guidelines

We welcome contributions to CyberX-Hacking-Kit! Here's how you can help:

 How to Contribute
1. Fork the repository
2. Create a new branch (`git checkout -b feature/your-feature`)
3. Commit your changes (`git commit -am 'Add some feature'`)
4. Push to the branch (`git push origin feature/your-feature`)
5. Open a Pull Request

 Contribution Rules
- Only submit legal, ethical hacking resources
- Verify all links work before submitting
- Keep descriptions concise and accurate
- Categorize resources appropriately
- Update documentation when adding new tools

## Code Standards
- Scripts should include proper error handling
- Include comments explaining complex code
- Follow the existing directory structure

## Reporting Issues
Please open an issue if you find:
- Broken links
- Outdated information
- Security concerns
- Missing categories
